# 每日法学经典

一个用于持续发布“法学经典著作解读”的静态网站项目。

## 内容原则

每日选择一部公开可查、具有较高学术影响力的法学经典著作，尽量避免重复。优先覆盖法理学、宪法学、行政法、民法、刑法、国际法、法律史、法律社会学、比较法及数字法等领域。

每篇解读重点包括：

1. 基本信息与写作背景
2. 全书核心问题与论证结构
3. 主要观点（含可核验原文及版本定位）
4. 学术影响
5. 主要争议与批评
6. 容易被误读的地方
7. 通俗总结
8. 公开查阅来源

## 核心要求

- 优先使用原始文献、权威馆藏页面、权威出版社版本及代表性研究文献；
- 严格区分初版、修订版、译本和后世整理版本；
- 不编造原文、页码或出处；
- 不把二手文献概括冒充作者原话；
- 不把后世理论术语倒写成作者本人的概念；
- 对“首次提出”“奠基人”“创始人”等表述保持谨慎；
- 如最新研究修正传统说法，应明确说明二者区别。

## 站点结构

- `index.html`：最新一期与站点首页
- `archive.html`：历史归档
- `data/books.json`：文章索引数据
- `assets/style.css`：页面样式
- `PROMPT.md`：完整内容生成规范

后续将接入每日自动生成、去重、归档与 GitHub Pages 发布流程。
