Token：模型怎样把一句话拆成可处理的小片段

今天只弄懂一件事：你输入一段文字之后，大模型为什么不能直接“照着文字看”，而要先把它拆成一些小片段？

先把 Token 记成一句人话

Token 就是大模型处理文字时使用的“小片段”。一句话进入模型前，会先被拆成若干这样的片段，模型再按照这些片段继续处理。

这一课先不要求你懂

后面会出现 Embedding、Transformer 等词。今天不需要理解它们的技术细节，只要知道：Token 是文字进入模型后的第一站。

一、先看一个最简单的例子

假设你输入一句话：“人工智能正在改变法律研究。”

人读这句话时，会自然按照汉字、词语和语义去理解。但模型在真正计算之前，要先把整句话拆成若干可以逐个处理的片段。每一个这样的片段，就是一个 Token。

只看机制，不代表某个具体模型的真实切分
人工智能正在改变法律研究。

这里的切分只是为了帮助理解。真实模型可能拆得更细，也可能组合得不同。不同模型使用的切分规则并不完全一样。

因此，理解 Token 最重要的第一步，不是记住某种固定切法，而是先建立一个直觉：模型处理的不是完整句子，而是把句子拆成一小段一小段之后再处理。

二、为什么模型要先把文字拆开？

因为现实中的文字太复杂了。新词、人名、公司名称、英文缩写、代码、符号每天都会出现。如果模型只能认识一个固定的“完整词表”，一遇到没见过的新词就很难处理。

所以更实用的办法是：把文字拆成较小的片段，再用这些片段去组合出各种词和句子。常见词可能作为较大的片段出现，少见词则可以拆得更细。这样不用给世界上每一个词都单独准备一个位置。

常见内容

可能直接成为一个较完整的片段，处理起来更省步骤。

少见内容

可以继续拆成更小片段，所以新词、姓名、代码也不至于完全无法处理。

最终目的

用一套有限的基本片段，覆盖尽可能多的真实文字。

三、一句话进入模型，大致经过什么步骤？

今天只需要看懂前三步
① 你输入文字例如：“人工智能法治”
→
② Tokenizer 切分Tokenizer 可以先理解成“切分器”：按照模型自己的规则把文字拆成 Token
→
③ Token 获得编号每个 Token 在模型使用的词表中都有自己的编号
→
④ 继续交给模型计算后面还要把编号变成模型能计算的一组数字，再进入模型主体
新词备注｜Tokenizer
Tokenizer 后面不会单独作为大专题，但你只需要把它理解成“负责把文字拆成 Token 的工具或规则”。不同模型可以使用不同的 Tokenizer。
新词预告｜Embedding
下一课会专门讲。今天只需要知道：Token 得到编号之后，还要再被转换成一组数字，模型才能真正开始计算。这个转换过程与 Embedding 有关。现在不用理解“一组数字”在数学上叫什么，也不用先学“向量”。
新词预告｜Transformer
后面会用多课专门讲。今天只把它理解成“大模型内部负责继续处理这些信息的核心结构”即可。

四、到这里，Token 可以怎样准确定义？

Token 是模型按照自己的切分规则，从文字中得到的基本处理片段。每个 Token 都能对应到模型词表中的一个编号。模型正是以这些片段及其编号为起点，继续完成后续计算。

这个定义里有三个关键词：

“模型自己的规则”

Token 怎么切，不完全按照我们日常理解的“字”和“词”来决定。

“基本处理片段”

模型先把长文本拆开，再逐步处理这些片段之间的关系。

“有对应编号”

模型不会一直拿着汉字或英文字母做计算，而是先把片段转换成可识别的编号。

五、理解清楚以后，再看它“不是什么”

Token 不一定等于一个汉字中文里，一个 Token 可能是一个字，也可能包含多个字；具体取决于模型使用的切分规则。
Token 不一定等于一个单词英文单词也可能被拆成几个 Token，尤其是少见词、长词、姓名或特殊写法。
Token 没有固定字数所以“128K Token”不能直接理解成“12.8万个汉字”或“12.8万个英文单词”。
Token 化也不是脱敏把文字切开并编号，只是改变了表示方式，并不意味着原来的内容已经无法恢复或无法识别。

六、为什么网信法研究者要知道 Token？

第一个直接用途：别把“格式变化”误当成“数据消失”。

在大模型训练、企业内部AI应用或者数据跨境场景中，可能会出现这样的说法：原始文字已经被转成 Token，所以已经不是原来的数据了。这个结论不能只凭“Token 化”得出。

原因很简单：Token 化的主要作用是让模型更方便处理文字，而不是让文字失去原有含义。如果系统仍然能够根据这些 Token 对应回原来的文字内容，那么就不能仅因为数据换了一种表示形式，就认定个人信息、商业秘密或者内部资料已经完成脱敏。

上下文窗口

模型一次能处理多少内容，通常按 Token 计算，而不是直接按页数、汉字数或单词数计算。

模型计费

很多模型服务会统计输入和输出用了多少 Token，因此 Token 也是理解AI服务价格的基础单位。

数据治理

研究训练数据、日志、跨境传输时，要看内容是否还能被识别和恢复，而不能只看它是否已经变成 Token。

七、这一课只需要带走三句话

第一句

Token 是大模型处理文字时使用的基本小片段。

第二句

一段文字进入模型前，会先被拆成 Token，并给这些 Token 分配编号。

第三句：Token 的边界不是固定的，也不能把 Token 化直接理解成匿名化或脱敏。

研究延伸

论文问题

数据表示形式变化与个人信息可识别性的法律判断

可以研究：一段文字从原文变成 Token、数字编号乃至其他技术表示后，什么时候仍应被视为可识别的信息？法律上的“匿名化”应当看数据长什么样，还是看现实中能不能重新对应到人或内容？

智库问题

政企大模型数据处理中的“技术转换不等于脱敏”风险

可梳理政务、金融和企业大模型中原始文本进入系统后的各个环节，防止把 Token 化、格式转换等普通技术处理误当成真正的脱敏措施。
