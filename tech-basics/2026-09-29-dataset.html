数据集：模型训练时的数据到底是什么样的？

今天只解决一个问题：我们常说“大模型用海量数据训练”，这些数据在真正进入训练前，到底是什么形态？

最简单的正面定义

数据集，就是为了训练、验证或测试模型，按照一定规则整理成的一组数据样本。它不是“互联网上所有东西”的统称，而是已经被选择、处理并组织成可供模型使用的数据集合。

一句话建立直觉

像老师出题前准备题库：原始书本、新闻和网页只是材料来源；真正的题库还要经过挑选、整理、去重和分类。

一、原始材料怎样变成数据集？

从“有数据”到“可用于训练”
原始来源网页、图书、代码、图片、业务数据等
→
筛选与清洗去掉明显低质、异常或不需要的内容
→
去重与整理减少重复，并形成可处理的数据单元
→
划分用途哪些用于训练，哪些留作验证或测试
→
转成模型输入文本再被 Token 化，进入训练计算

因此，“某网站曾被抓取”与“某段内容最终进入有效训练数据集”不是一回事。中间还可能发生过滤、删除、去重、格式转换和版本更新。GPT-3 的公开论文就明确记载过对 Common Crawl 进行质量过滤、文档级去重，并加入其他高质量语料。

二、数据集里的“一条数据”长什么样？

没有一种统一格式。分类任务的数据集可能是一列文本加一列标签；问答数据集可能包含问题、背景材料和答案；图像任务则可以把图片与标签放在一起。Hugging Face 的数据集文档也把数据集描述为由“行”和不同类型“列”组成的结构。

新词备注｜样本
今天把“样本”理解成数据集里可以被单独拿出来的一条训练或评测材料。它可能是一段文本、一组问答，也可能是图片和说明的组合。

对语言模型预训练来说，工程实现还会把长文本切分、拼接或转换为 Token 序列。不同模型和训练阶段处理方法不同，不能把某一种数据格式写成所有大模型的固定做法。

三、为什么还要分训练集、验证集和测试集？

训练集

模型真正用来更新参数、学习规律的数据。

验证集

训练过程中用来检查效果、比较不同设置的数据。

测试集

最后用于检验模型面对“没训练过的数据”表现如何。

三者分开的原因很直观：如果考试题已经出现在练习题里，分数就不能真实说明模型能否处理新问题。Google 的机器学习课程因此特别强调训练、验证和测试数据应当区分，并避免测试样本与训练样本重复。

四、正面概念讲清以后，再看三个常见误解

误解 01“训练数据就是互联网上抓到的全部原始文件。”——原始来源只是上游，最终数据集通常还经过筛选、清洗、去重和格式处理。
误解 02“数据集越大一定越好。”——数量只是一个因素，重复、低质或与实际任务差异过大的数据都可能降低价值。
误解 03“测试集只是训练集的一小部分，混进去也没关系。”——如果测试数据泄漏进训练过程，评测结果可能被高估。

五、法治连接：争议真正落在哪一层数据？

“数据来源”与“有效训练数据集”应当分开审计。

在版权、个人信息、数据来源合规或模型安全争议中，只列出“抓取过哪些网站”往往不够。更关键的证据还包括：某一版本数据集实际保留了哪些内容，经过什么过滤和去重规则，何时生成，后来是否删除或替换，以及训练时实际调用的是哪个版本。

这意味着训练数据治理至少存在一条可区分的证据链：原始来源 → 处理规则 → 有效数据集版本 → 训练使用记录。前一层存在某项数据，并不能自动证明后一层一定使用了它；反过来，如果缺少版本和处理记录，也很难解释某项内容究竟怎样进入训练过程。

六、把这一课转成两个研究问题

论文问题

训练数据集的法律可审计边界

可研究从原始数据来源到有效训练样本之间，筛选、去重、删除和版本变化应如何进入版权、个人信息与侵权举证规则。

智库问题

高风险大模型训练数据最小留痕规范

可研究是否应统一记录数据来源类别、清洗规则、去重方式、数据集版本、训练调用时间和评测隔离情况。

七、这一课只需要带走三句话

第一句

数据集不是原始材料的简单堆积，而是经过选择和组织后供训练或评测使用的数据集合。

第二句

原始来源、有效训练数据集和最终训练记录是三个不同层次，法律审计时不能混为一谈。

第三句：训练集、验证集和测试集分开，是为了让模型真正接受“没有练过的题”的检验。

原始材料

  • Google Machine Learning Crash Course：Dividing the original dataset——介绍训练集、验证集、测试集的基本区别和数据泄漏问题。
  • Hugging Face Datasets：Dataset features——展示数据集怎样由不同类型的列、标签、文本、图像等结构化组成。
  • Brown et al. (2020), Language Models are Few-Shot Learners——GPT-3 论文第2.2节说明训练数据的过滤、去重和混合过程。
  • Gebru et al., Datasheets for Datasets——提出记录数据集动机、组成、收集过程和推荐用途，以提高透明度与问责性。
