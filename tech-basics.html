课程怎么学

每一课只解决一个问题，不堆术语。先看图，再理解机制，最后才讨论它为什么会影响法律研究。

先看图用流程图、关系图或对照表把技术过程先搭起来。
再讲机制只解释研究中真正需要知道的技术细节，不把课程写成编程教材。
最后接法治明确指出技术事实会改变什么责任节点、证据判断或治理结构。

八个模块

MODULE 01

基础积木

Token、Embedding、参数、训练与推理、损失函数、预训练、概率生成。

MODULE 02

Transformer

Attention、自注意力、Q/K/V、多头注意力、位置编码、前馈网络、Decoder-only。

MODULE 03

模型如何炼成

训练数据、SFT、RLHF、DPO、合成数据、蒸馏、后训练与评测。

MODULE 04

能力与推理

上下文窗口、采样、幻觉、推理模型、KV Cache、MoE、多模态。

MODULE 05

RAG 与智能体

向量数据库、检索增强、工具调用、Agent、Memory、MCP 与跨应用操作。

MODULE 06

部署与基础设施

API、本地部署、量化、GPU、训练与推理成本、云边端与模型服务链。

MODULE 07

安全与失效

Prompt Injection、越狱、投毒、模型抽取、隐私泄露、权限、沙箱与评测。

MODULE 08

技术到法律

可解释、可审计、责任链、数据跨境、平台化、互操作、行政使用与持续监管。
